Nova Orbis city data

Pick a suggested place. Step 1 asks the geocoder for its coordinates (the same call the game makes) and shows the exact map request the game would send for a 500 m city. Step 2 sends that one request and saves the answer as a file you can host. Each of those buttons sends a single request. "Get every queued place" works through the queue instead: each place in turn, on each map server in turn until one answers, one request at a time.
